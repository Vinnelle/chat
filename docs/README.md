# Documentation

For using chat:

- [Getting started](getting-started.md): downloading and checking a release, where to put it, and a
  first session.
- [Usage](usage.md): the full-screen UI, keys, commands, settings, command line options and
  updating.
- [Security and privacy](security.md): encryption, verify codes, signing identities, `:move`, calls,
  the lock screen and panic key, and what chat can't hide.
- [Routing](routing.md): UDP, the DHT, LAN discovery, port mapping, Nostr relays, Tor and bridges,
  and what each one sees.
- [Files and pictures](files.md): sending, fetching and showing files, and what a picture says about
  you.
- [Saving settings and keys](saves.md): `:install`, more than one save, device locks, security keys
  and authenticator apps, histories, kept rooms, and the shadow passphrase.

For reviewing or working on it:

- [Wire protocol](protocol.md): what chat sends over the network, byte by byte.
- [Architecture](architecture.md): how the source is laid out.
- [Building](building.md): building from source, cross builds for Windows and macOS, and the tests.
- [Releasing](releasing.md): how releases are made, signed and reproduced, and the backup key.
- [SECURITY.md](../SECURITY.md): the threat model, and how to report a vulnerability.
- [CHANGELOG.md](../CHANGELOG.md): what changed in each release.
